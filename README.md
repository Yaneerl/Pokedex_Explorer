# PokéDex Explorer

אפליקציה לגילוי פוקימונים, צפייה בפרטים, שמירת מועדפים והשוואת מדדי בסיס, עם נתונים אמיתיים מ-PokéAPI וממשק בהשראת מכשיר Pokédex.

## פיצ'רים מרכזיים

- **קטלוג (/):** חיפוש לפי שם חלקי או מספר, סינון לפי סוג, דור וסיווג, מיון, איפוס מסננים ודפדוף של עד 20 פוקימונים בעמוד.
- **פרטי פוקימון (/pokemon/:id):** תמונה, סוגים, תיאור באנגלית, שישה מדדי בסיס, יכולות, גובה ומשקל.
- **התפתחויות:** הצגת השרשרת המלאה, כולל הסתעפויות וקישורים לפרטי כל שלב.
- **Normal, Shiny ו-Mega:** בחירת הצורות הזמינות ב-API ועדכון התמונות והנתונים בהתאם, עם טיפול בתמונה חסרה.
- **מועדפים (/favorites):** הוספה והסרה באמצעות לב, עם שמירה ב-localStorage גם לאחר רענון; צורות של אותו מין חולקות מועדף אחד.
- **השוואה (/compare):** בחירה מחיפוש או ממועדפים, כולל צורות Mega, והשוואת מדדים, הפרשים, סכומים, יתרונות ותיקו. זו השוואת Base Stats בלבד, ללא חיזוי קרב.
- **Pokémon of the Day:** בחירה יומית הנשמרת בדפדפן לפי התאריך המקומי.

הממשק כולל התאמות למובייל, מצבי Loading, Error ו-Empty, טעינת Skeleton בפרטים ותמיכה בהפחתת תנועה. מצב החיפוש, המסננים והדפדוף נשמר בניווט חזרה לקטלוג, ללא רענון מלא.

## טכנולוגיות

React, Vite, TypeScript ו-React Router, עם CSS מקומי ו-fetch לשליפת נתוני PokéAPI.

פונט Lilita One נטען מקומית; [הרישיון](public/fonts/lilita-one/OFL.txt) ו[הקרדיט](public/fonts/lilita-one/CREDITS.md) מצורפים.

## התקנה והרצה

נדרשים Git, npm ו-Node.js בטווח `^22.22.2 || ^24.15.0 || >=26.0.0`, בהתאם לגרסאות החבילות שבפרויקט.

```bash
git clone https://github.com/Yaneerl/Pokedex_Explorer.git
cd Pokedex_Explorer
npm ci
npm run dev
```

פתחו את הכתובת שמציג Vite בטרמינל. נדרש חיבור לרשת לטעינת הנתונים; אין צורך בשרת נוסף, מפתח API או קובץ .env.

לבניית גרסת ייצור: `npm run build`. לתצוגת הבנייה המקומית: `npm run preview`.

בפריסה לאחסון סטטי יש להגדיר הפניה ל-`index.html` עבור נתיבי React Router, כדי שגם כניסה ישירה לעמוד תעבוד.

## מבנה התיקיות

```text
src/
  components/  עמודים ורכיבי ממשק
  hooks/       טעינת נתונים והתנהגות משותפת
  utils/       חיפוש, סינון, המרות והשוואה
  types/       טיפוסי TypeScript ותגובות API
  styles/      סגנונות משותפים ולפי עמוד
  test/        הגדרות ועזרי בדיקה
public/        נכסי SVG ופונט מקומי
```

## בדיקות

הבדיקות משתמשות ב-Vitest, ב-React Testing Library וב-jsdom, ומכסות לוגיקה, רכיבים, ניווט ושמירת נתונים. להרצה חד-פעמית:

```bash
npm run test
```

פקודות נוספות: `npm run test:watch` למצב צפייה בשינויים, `npm run typecheck` לבדיקת טיפוסים ו-`npm run lint` לבדיקת קוד. פקודת Build כוללת גם Typecheck.

בבדיקה האחרונה, בתאריך 3.11.2026, עברו 183 בדיקות בהצלחה, יחד עם בדיקות Typecheck, Lint ו-Build.
